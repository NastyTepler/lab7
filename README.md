## Выбранная СУБД
В работе используется встроенная база данных **H2** (режим в памяти, `jdbc:h2:mem:testdb`). Она не требует установки отдельного сервера и подключается через Maven-зависимость.

## Порядок подготовки
1. Скрипт `data/music-create.sql` выполняется программно при запуске и создает схему `study`, таблицу `music` и заполняет ее данными.
2. Данные из `data/books.json` читаются с помощью библиотеки Gson и загружаются в таблицы `visitors` и `books` без дубликатов (используется SQL-оператор `MERGE`).

## Команды сборки и запуска
1. Собрать проект: `mvn clean package`
2. Запустить программу: открыть класс `app.Main` в IDE и запустить метод `main()`.
